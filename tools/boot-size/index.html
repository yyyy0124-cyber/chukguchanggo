축구화 사이즈 표 확인

양쪽 발 길이를 입력하면 아디다스 성인 신발 표에서 해당 길이 또는 양옆의 표기를 확인합니다. 구매 사이즈를 단정하지 않습니다.

직접 계산하기

이 계산기의 입력값은 별도로 저장하거나 서버로 보내지 않습니다.

측정값과 신발 표기는 다릅니다

발 길이 265mm와 제품에 적힌 265 표기를 같은 값으로 취급하지 마세요. 이 도구가 찾는 것은 브랜드 표의 뒤꿈치부터 발끝까지의 길이입니다. 제품의 내부 길이를 계산하는 기능은 아닙니다.

현재 비교 범위는 발 길이 242~293mm이며 US는 남성 표기입니다. 다른 브랜드나 아동용 사이즈로 결과를 옮겨 쓰지 마세요.

발 길이를 확인하는 순서

  1. 종이를 바닥에 고정하고 뒤꿈치와 가장 긴 발가락의 위치를 표시합니다.
  2. 두 지점 사이의 길이를 mm로 잽니다. 양쪽 발을 각각 측정합니다.
  3. 두 값을 입력한 뒤 큰 발을 기준으로 나온 표를 확인합니다.
  4. 구매할 상품의 사이즈 안내와 비교합니다. 발볼과 발등은 이 계산에 포함되지 않습니다.

265mm를 입력하면 왜 두 행이 나오나요?

가상의 측정값이 왼발 263mm, 오른발 265mm라면 큰 발 265mm를 사용합니다. 확인한 표의 인접 값은 263mm와 267mm입니다. 도구는 두 행을 함께 보여 주며, 무조건 큰 사이즈를 사라고 결정하지 않습니다.

길이가 표에 정확히 있더라도 같은 브랜드의 모든 축구화에 같은 착화감을 보장하지 않습니다. 최종 선택은 해당 모델의 제품 안내와 실제 착용으로 확인하세요.
