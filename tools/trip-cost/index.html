축구 직관 경비 계산기

숙박비는 함께 나누고 나머지는 1인 기준으로 합산합니다. 직접 확인한 견적을 모두 원화로 입력하세요.

직접 계산하기

이 계산기의 입력값은 별도로 저장하거나 서버로 보내지 않습니다.

방값과 사람당 비용을 구분합니다

객실 1개가 1박 20만원이고 3박을 두 명이 나누면 1인 숙박비는 30만원입니다. 방값을 이미 절반으로 나눠 입력하고 인원을 다시 2명으로 넣으면 비용을 두 번 나누게 됩니다.

교통비·티켓·하루 생활비는 처음부터 1인 금액으로 입력합니다. 여러 경기를 볼 때 티켓 칸에는 경기별 비용을 합한 값을 넣으세요.

계산 예시

아래 금액은 시장 가격이 아닌 가상 예산입니다. 왕복 교통 120만원, 1인 숙박 30만원, 티켓 15만원, 하루 생활비 8만원 × 4일이면 기본 예산은 197만원입니다. 예비비 10%를 더하면 216만 7천원입니다.

박수와 체류일은 같은 값이 아닐 수 있습니다. 늦게 도착하거나 야간 이동을 한다면 일정표를 기준으로 각각 입력하세요.

표에 없는 비용을 놓치지 마세요

발권 수수료·수하물·보험·공항 이동이 이미 각 견적에 들어 있는지 확인합니다. 포함되지 않았다면 해당 항목의 입력 금액에 합산하세요. 환불 불가 조건과 경기 일정 변경도 예약 전에 따로 확인해야 합니다.

이 도구는 환율이나 실시간 가격을 가져오지 않습니다. 환율 변동과 결제 수수료를 고려한 원화 견적을 입력하고, 예비비를 넣어 상한 예산을 비교하세요.

경기 관람 계획을 세우기 전 확인할 것

내용이나 계산에 오류가 있다면 축구창고에 알려주세요.
