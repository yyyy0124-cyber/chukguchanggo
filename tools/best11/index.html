나만의 베스트11 메이커

포메이션과 11명의 이름을 넣어 라인업을 만들고 PNG 이미지로 저장하세요. 입력한 명단을 무작위로 배치할 수도 있습니다.

라인업 만들기

골키퍼부터 공격수 순서입니다. 이름이 빈 자리는 ‘선수 1’처럼 표시합니다.

PNG 이미지 저장

명단을 공유하는 순서

  1. 팀의 기본 배치에 맞는 포메이션을 고릅니다. 골키퍼까지 합쳐 11자리입니다.
  2. 포지션 옆에 이름을 입력합니다. 팀 이름은 생략해도 됩니다.
  3. 미리보기에서 배치와 이름을 확인합니다. 긴 이름은 그림 안에 맞게 작게 표시됩니다.
  4. PNG 이미지로 저장한 뒤 모임 공지나 자신의 게시물에 첨부하세요.

포메이션을 바꾸면 무엇이 달라지나요?

4-3-3은 수비 4명·미드필더 3명·공격수 3명, 4-4-2는 수비 4명·미드필더 4명·공격수 2명을 표시합니다. 3-5-2에는 측면의 윙백을, 4-2-3-1에는 수비형 미드필더 2명과 공격형 미드필더 3명을 구분해 배치했습니다.

이름은 입력 순서대로 유지되므로 포메이션을 바꾼 뒤 각 선수의 자리를 다시 확인하세요. 왼쪽·오른쪽은 위쪽으로 공격하는 팀 기준입니다. 배치도는 기본 위치를 보여주며 경기 중 움직임이나 전술 효과를 예측하지 않습니다.

랜덤 배정은 이렇게 쓰세요

11명을 모두 입력한 뒤 ‘입력한 11명 섞기’를 누르면 입력한 사람들끼리 자리가 바뀝니다. 골키퍼 자리도 포함됩니다. 포지션 적성이나 실력을 반영하는 팀 편성 기능은 아니므로 놀이용 배치 후 필요한 자리는 직접 수정하세요.

모임에서 각자 한 명씩 이름을 정해 ‘우리의 베스트11’을 만들거나, 팀원 1~11이라는 예시 명단으로 먼저 배치를 시험해볼 수 있습니다. 실존 선수의 현재 소속이나 능력 데이터를 자동으로 불러오지는 않습니다.

자주 묻는 질문

선수 사진이나 팀 엠블럼도 넣을 수 있나요?

현재는 이름과 포지션을 표시하는 도구입니다. 사진이나 엠블럼을 불러오지 않아 명단 중심으로 간단하게 공유할 수 있습니다.

명단은 저장되나요?

입력한 이름은 서버로 전송되지 않습니다. 페이지를 닫기 전에 PNG를 저장하세요. 저장된 PNG는 이미지이므로 이름을 바꾸려면 이 도구에서 다시 만들어야 합니다.

PNG는 어떻게 확인하나요?

저장 버튼을 누른 뒤 브라우저의 다운로드 목록이나 기기의 파일 앱에서 확인하세요. 모바일에서는 브라우저에 따라 이미지 미리보기가 열릴 수도 있습니다.
