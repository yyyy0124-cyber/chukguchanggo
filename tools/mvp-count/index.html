직접 사용하기

계산·동작 기준

같은 이름은 합산합니다. 동점은 공동 순위이며 다음 순위는 건너뜁니다.

사용 예시

5표·5표·3표는 공동 1위 두 명과 3위 한 명입니다.

결과를 읽을 때

실제 투표를 받는 서비스가 아닌 입력한 결과의 집계기입니다. 표수가 없는 줄은 오류로 표시합니다.
